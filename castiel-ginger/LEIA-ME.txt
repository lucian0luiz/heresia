CASTIEL GINGER — V7 EDITÁVEL

Abra index.html no navegador.

FUNCIONALIDADES:
- VIDA, SANIDADE, REPUTAÇÃO e RADIAÇÃO usam hexágonos SVG e setas funcionais.
- Todos os atributos usam hexágonos SVG e setas funcionais.
- "Modo de Edição" libera edição direta de textos, listas, tabelas, carga, defesas, perícias etc.
- Os botões "+" são funcionais:
  • Posses: cria uma nova linha com Item / Dano / Peso.
  • Talentos conhecidas: cria um novo talento com o mesmo ícone/layout.
  • Limitações: cria uma nova limitação com o mesmo ícone/layout.
- No modo de edição aparece "×" para remover linhas das listas dinâmicas.
- Alterações são salvas automaticamente no navegador (localStorage).
- Exportar JSON salva os dados da ficha.
- Importar JSON carrega outra ficha.
- Restaurar ficha volta aos dados originais.

ARQUIVOS:
- index.html
- style.css
- script.js
- assets/

Observação: imagens decorativas continuam sendo assets; os dados da ficha são HTML/JS editáveis.
